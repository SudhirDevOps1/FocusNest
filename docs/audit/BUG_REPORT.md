# FocusNest Master Bug Report (Baseline Audit)

Severity scale:
- **P0**: Application crashes, core unit/CI breakage, data corruption, or security defects.
- **P1**: Core features fail to enforce or operate reliably.
- **P2**: Incorrect behavior, permission refresh drift, or analytics classification errors.
- **P3**: UI/UX inconsistencies, copy/branding gaps, or documentation/DevOps polish.
