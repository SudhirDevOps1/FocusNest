# Getting Started with FocusNest

1. Install FocusNest and complete the **10-step Onboarding** (every optional permission can be skipped and enabled later).
2. Grant **Usage Access** (`PACKAGE_USAGE_STATS`) when prompted so FocusNest can read real daily screen time and app opening counts via `UsageStatsManager`.
3. Enable the optional **Accessibility Service** if you want real-time app blocking, the **Mindful Launch Pause Curtain**, and configurable Reels/Shorts pause screens.
4. Set your daily screen-time and focus goals, arm any apps for Launch Pause or time limits under **Shield**, and start a Focus session with optional offline **Ambient Soundscapes** from the **Focus** tab.
5. Check out your **Weekly Wellbeing Report Card** under **Insights** and your **Evening Wind-Down Checklist** under **More > Mindful Usage Tools**.
