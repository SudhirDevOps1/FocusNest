TRANSPARENT PERMISSIONS & UPDATES

How Updates Work Without Internet Permission

Unlike closed wellbeing apps that phone home daily, FocusNest keeps its APK cleanly offline. Tapping Check Releases on GitHub in Settings delegates a standard Android ACTION_VIEW link to your chosen browser at https://github.com/OWNER/FocusNest/releases/latest—so FocusNest itself never opens a network socket.
