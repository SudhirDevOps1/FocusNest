# FocusNest Roadmap

Maintained by **Sudhir Kumar** ([SudhirDevOps1](https://github.com/SudhirDevOps1)) — 100% free, open-source, offline-first, and zero `INTERNET` permission forever.

- **v1.0.0 (Shipped)**: Complete offline digital wellbeing, focus timer, app/website/short-form blocker, 11 unlock challenges, widgets, AES-256-GCM encrypted backups, and documentation.
- **v1.1.0 (Shipped)**: Habits & routines tracker, 12th Breathing unlock challenge, category limits & grace periods, monotonic timer recovery, replay-protected QR tokens, per-app VPN routing, Quick Settings tile, Hindi localization, and Room `MIGRATION_1_2`.
- **v1.2.0 (Current — Production Hardened)**:
  - Tablet & foldable adaptive two-pane layouts + `NavigationRail`
  - Pure-Kotlin offline synthesized ambient soundscapes (`AudioTrack`)
  - Mindful app-launch breathing pause curtain + weekly printable/PDF report card + bedtime wind-down checklist
  - Zero-internet GitHub Releases handoff + startup `StartupPhase` state machine
  - Stride-safe CameraX QR scanner, async `VpnConnectionState` + Domain Tester, modular blocking engine + `SystemPackageClassifier`
  - 27-section interactive showcase website + SHA-pinned GitHub CI/CD & Release Please
- **v1.3.0 (Planned)**:
  - Per-app notification channel muting rules inside Focus profiles
  - Wear OS companion focus timer tile (strictly local Bluetooth companion sync)
  - Expanded OEM background-execution setup helpers & community translations
- **v1.4.0 (Exploring)**:
  - Optional local Wi-Fi / peer-to-peer E2EE backup transfer between user-owned devices (disabled by default; strictly LAN/local without cloud servers)
